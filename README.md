# 智能语音助手

基于Transformer的语音识别智能助手，可以通过语音识别指令操控电脑。

## 功能特性

- 🎤 **语音识别**: 使用OpenAI Whisper Transformer模型进行语音识别
- 🔧 **智能命令解析**: 自动识别用户意图并执行相应操作
- 🌐 **浏览器搜索**: 支持多种搜索引擎
- 📱 **应用管理**: 一键打开/关闭应用程序
- 🖥️ **系统控制**: 截图、锁屏、关机、重启等系统操作
- 🔊 **音量控制**: 调节系统音量
- 💬 **语音反馈**: TTS语音播报执行结果
- 🎨 **现代化界面**: 简洁美观的图形用户界面
- ✅ **智能纠错**: 自动纠正语音识别错误

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动程序

```bash
python main.py
```

## 项目结构

```
voice-assistant/
├── main.py                 # 主程序入口
├── config.py              # 配置文件
├── voice_assistant.py     # 核心助手类
├── asr_model.py          # Transformer语音识别模型
├── audio_capture.py      # 音频采集模块
├── command_parser.py     # 命令解析器
├── computer_controller.py # 电脑控制模块
├── voice_feedback.py     # 语音反馈模块
├── gui.py                # 图形界面
├── requirements.txt      # 依赖列表
└── commands.json         # 命令配置
```

## 技术说明

- **语音识别**: Whisper small 模型（244M参数）
- **语言支持**: 中文（简体/繁体）
- **离线工作**: 完全支持，无需网络连接
- **纠错功能**: 自动纠正语音识别中的常见错误
